ProblemHub API Documentation

JSON API endpoints designed for cross-platform clients, mobile applications, and external academic integrations.

GET /api/v1/problems
Test Endpoint

Retrieves list of all approved problem statements. Supports optional query parameters: keyword, domain, and difficulty.

Example Response: 
{
  "success": true,
  "message": "Retrieved 12 problem statements",
  "data": [
    {
      "id": 1,
      "title": "Smart Waste Collection Route Optimization",
      "domain": "Environment",
      "difficulty": "Intermediate",
      "suggestedTech": "Java, MySQL, Leaflet"
    }
  ],
  "timestamp": 1728954000000
}
GET /api/v1/problems/{id}
Test ID #1

Retrieves single problem statement by ID including context, required skills, deliverables, and duration.

GET /api/v1/recommendations
Test Recommendations

Executes the Content-Based Filtering algorithm against current student profile or query parameters (skills, interests, year) and returns ranked matches with percentage score.

Response Data Features: score, matchPercentage, matchedSkills, domainMatched, explanation
GET /api/v1/stats
Test Stats

Summary platform counts (total problems, registered student projects, verified solutions, active batches).
